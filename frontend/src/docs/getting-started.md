# Getting Started

## Prerequisites

Before you begin, make sure you have:

- **An account** — You need a valid login (email + password via the Cognito sign-in page). Ask your admin if you don't have one.
- **Documents to assess** — PDF, TXT, MD, or image files containing the design, policy, or architecture you want reviewed.
- **A modern browser** — Chrome, Firefox, Edge, or Safari (latest versions recommended).

## Create a Project

1. Click **+ New Project** from the Projects page
2. Enter a name and optional description
3. Optionally select an organizational context to tailor the review
4. Upload one or more design documents (PDF, TXT, MD, or images)
5. Click **Create & Start Review**

The system uploads your documents to secure storage and immediately begins the review process.

## The Review Process

Once triggered, the review follows this flow:

1. **Planning** — An AI planner analyzes your document and creates a review strategy, selecting which agents to use, their depth, and focus areas
2. **Plan Approval** — You see the proposed plan and can customize it (adjust agents, depth, focus areas, enable/disable quality coaching) or approve as-is
3. **Agent Execution** — Specialized agents review your document in parallel (or sequentially if configured)
4. **Quality Evaluation** — A judge evaluates each agent's findings for completeness, specificity, and actionability
5. **Results** — Findings are stored and displayed organized by agent

## Viewing Results

After the review completes, the project detail page shows:

- **Summary cards** with finding counts by severity
- **Agent tabs** to browse findings per agent
- **Quality scores** showing how well each agent performed
- **Chat** to ask follow-up questions to any agent

## Live Review

Click **View Live** during an in-progress review to watch the agents work in real time. The flow graph shows each agent's progress, coach iterations, and quality evaluation as they happen.
