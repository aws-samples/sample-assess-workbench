# Using Chat

## Agent Chat

After a review completes, you can chat with any agent to ask follow-up questions. Each agent has its own chat context — it knows about the document and its own findings.

### What to Ask

- "Why did you flag the authentication approach as high severity?"
- "What specific changes would you recommend for the database encryption?"
- "Are there any compliance implications I should be aware of for GDPR?"
- "Can you elaborate on the scalability concern with the message queue?"

### How It Works

- Select an agent tab in the chat panel (right side of the project detail page)
- Type your question and send
- The agent responds with context from the document and its findings
- Chat history is preserved — you can return to a project and continue the conversation

### Tips

- Be specific — reference finding IDs or document sections for targeted answers
- Each agent only knows about its own domain — ask architecture questions to the architecture agent, not the security agent
- The chat uses the same AI model as the review, so it understands the full document context
